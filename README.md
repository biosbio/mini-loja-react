# Mini Loja

Este projeto é uma aplicação de loja virtual desenvolvida com React e Vite. O objetivo é fornecer uma base simples e eficiente para criar e gerenciar produtos, carrinho de compras e fluxo de checkout.

## Tecnologias Utilizadas
- [Visual Studio Code](https://code.visualstudio.com/) como editor de código recomendado
- [Node.js](https://nodejs.org/) (recomendado versão 18 ou superior)
- [React](https://react.dev/)
- [npm](https://www.npmjs.com/) para gerenciamento de dependências e scripts
- [JavaScript](https://developer.mozilla.org/docs/Web/JavaScript) como linguagem principal
- [npm](https://www.npmjs.com/) para gerenciamento de dependências e scripts

## Como acessar e rodar o projeto

1. **Clone o repositório:**
      ```bash
      git clone https://github.com/biosbio/mini-loja.git
      cd mini-loja
      ```

2. **Instale as dependências:**
      ```bash
      npm install
      ```

3. **Inicie o servidor de desenvolvimento:**
      ```bash
      npm run dev
      ```

4. **Acesse no navegador:**
      Abra [http://localhost:5173](http://localhost:5173) para visualizar a aplicação em funcionamento.
